## 1. 项目背景

### 1.1 为什么做这个项目
Day-01 完成了纯前端 AI 应用，所有能力受限于浏览器，无法调用服务端工具、无法持久化、无法对接外部 API。
Day-02 的核心跃迁是：**打通前后端，让 LLM 不再"只会聊天"，而能"听懂人话 → 调用工具 → 开口回答"**。

### 1.2 为什么用微信小程序
- **入口即达**：微信扫一扫 / 搜索即用，无需安装、无需注册（游客模式）
- **原生能力**：录音、音频播放、地图组件微信原生内置，比 Web 端更稳
- **移动场景**：语音助手天然适合手机端（边走边说、问路、查天气）
- **工程价值**：沉淀「微信小程序 + FastAPI + 大模型 + 第三方 MCP」的标准全栈模板

### 1.3 业务价值
- **教学价值**：一个项目串起 ASR / LLM / MCP / TTS 四大能力，闭环 LLM LOOP（思考 → 调工具 → 看结果 → 再思考）。
- **产品价值**：可作为微信内"语音助手"原型，扩展为智能客服、语音 IoT 控制、出行规划等场景。

## 2. 项目目标

### 2.1 核心目标
打造一个**微信小程序语音 AI 助手**：用户按住说话 → 系统理解 → 调用合适的工具（地图、天气等）→ 用语音回答。

### 2.2 关键结果（OKR）
| O | KR | 衡量指标 |
|---|---|---|
| O1 完成四大能力闭环 | KR1 ASR 准确率 | 中文短句 WER ≤ 10% |
| O1 | KR2 LLM 工具调用成功率 | 调用成功 ≥ 95% |
| O1 | KR3 MCP 工具返回正确率 | 地图场景 ≥ 90% |
| O1 | KR4 TTS 端到端延迟 | 从发请求到播放 ≤ 2.5s |
| O2 体验流畅 | KR5 端到端 P95 响应 | ≤ 4s（含 ASR+LLM+TTS） |
| O2 | KR6 小程序兼容 | iOS / Android 微信 8.0+ 均可正常使用 |
| O3 工程化 | KR7 代码可维护 | 模块化 + 单测覆盖核心链路 |

## 4. 功能需求

### 4.1 核心功能（必须 P0）

#### F1. 语音输入（ASR）
- **输入**：用户**按住**麦克风按钮说话，松开发送（微信原生 `wx.getRecorderManager`）
- **处理**：小程序录音（Android 输出 mp3 / iOS 输出 aac）→ `wx.uploadFile` 上传后端 → 后端 ffmpeg 转 wav/pcm → 阿里云 ASR 识别
- **输出**：识别文本实时显示在聊天界面
- **边界**：
  - 单次录音最长 **60s**（微信上限）
  - 支持中文（普通话），可扩展英文
  - 录音失败（权限拒绝/静音）给出明确错误提示
  - 微信授权弹窗由系统自动处理，被拒后在设置页引导「右上角…→设置」开启麦克风

#### F2. LLM 对话（思考 + 工具调用）
- **输入**：用户问题文本（语音转文字或直接打字）
- **处理**：
  1. 后端组装消息（系统提示词 + 历史 + 当前问题）
  2. 调用百炼 Qwen / Deepseek（支持 Function Calling）
  3. 若模型决定调用工具 → 调高德 MCP 工具 → 把结果回填给模型 → 再次推理
  4. 流式返回（WebSocket）最终答案
- **输出**：分片文本增量推送到小程序
- **支持工具**：
  - `maps_geocode`（地址 → 坐标）
  - `maps_search_around`（附近搜索）
  - `maps_direction`（路径规划）
  - `get_weather`（天气查询）
  - `web_search`（可选，P1）

#### F3. 语音输出（TTS）
- **输入**：LLM 生成的回复文本
- **处理**：后端分句 → 阿里云 TTS 合成 → 音频 → 通过 WebSocket 推送
- **输出**：小程序 `wx.createInnerAudioContext` 自动播放，可暂停/打断
- **边界**：
  - 单句长度 ≤ 200 字
  - 音色可切换（女声 / 男声 / 方言）
  - 播放时可随时点"停止"

#### F4. 流式响应（LLM LOOP 可视化）
- 用户**实时看到**以下事件流：
  1. `asr_partial` - ASR 识别中
  2. `asr_final` - 识别完成
  3. `llm_thinking` - LLM 开始思考
  4. `tool_calling` - 调用工具（含工具名 + 参数）
  5. `tool_result` - 工具返回结果
  6. `llm_streaming` - 文本分片流式输出
  7. `tts_synthesizing` - TTS 合成中
  8. `tts_playing` - 开始播放
  9. `done` - 完成

#### F5. 地图结果展示
- 工具返回 POI 后，聊天流中嵌入**地图卡片**（小程序原生 `<map>` 组件）
- 点击卡片可**全屏打开地图**，查看标记点、点击标记查看 POI 详情
- 提供"在地图中打开"（调起微信内置地图能力 / 复制定位文案）

### 4.2 辅助功能（P1）

#### F6. 会话历史
- 同一会话内保持上下文（多轮对话）
- 支持新建会话 / 切换会话（会话列表页）
- **游客模式**：会话历史优先存本地 `wx.setStorageSync`；后端按 `session_id` 可选持久化（SQLite）

#### F7. 设置页
- 切换 LLM 厂商（百炼 / Deepseek）
- 切换 TTS 音色 / 语速
- 开关 TTS
- 调整系统提示词
- 开关工具白名单（地图 / 天气）

#### F8. 工具调用可视化
- 聊天流中展示"AI 正在调用 XX 工具 / 已获得结果"卡片（工具名、参数、返回摘要）

#### F9. 错误处理与降级
- ASR 失败：保留录音 + 提示用户重试
- LLM 失败：降级到纯文字对话
- TTS 失败：文字正常显示
- 工具调用失败：告知用户，AI 继续对话
- 网络断开：顶部提示 + 重连自动恢复

### 4.3 扩展功能（P2）

- 微信一键登录（游客 → 绑定 openid，同步云端历史）
- 用户上传文档做 RAG
- 自定义 Skill 插件（让用户自己加工具）
- 消息分享到微信好友 / 朋友圈
- 订阅消息推送（"结果已就绪"通知）

## 5. 非功能需求

| 类别 | 指标 | 要求 |
|---|---|---|
| **性能** | 端到端 P95 延迟 | ≤ 4s |
| | 首字延迟（TTFB） | ≤ 1.5s |
| | 音频流式播放 | TTS 分句后立即播放，不等全文 |
| **可用性** | 系统可用性 | 学习期 ≥ 95% |
| | 错误提示友好度 | 所有失败都有明确文字 + 建议 |
| **兼容性** | 微信版本 | iOS / Android 微信 8.0+ |
| | 基础库 | 3.0+（开发者工具最新稳定版） |
| **安全** | API Key | 仅后端持有，小程序端零密钥 |
| | 输入校验 | 防止超长文本 / 注入 |
| | 速率限制 | 单 IP 60 req/min（学习期可关） |
| **可维护** | 代码规范 | PEP8 / 小程序官方规范 |
| | 日志 | 结构化日志（JSON） + 请求链路追踪 |
| | 部署 | 一键 `docker-compose up` |
| **隐私** | 用户录音 | 不持久化（仅用于当前请求） |
| | 会话历史 | 默认本地存储，**可清空** |

## 6. 验收标准

### 6.1 功能验收
- [ ] US-01：长按麦克风录音并识别中文，识别文本实时显示
- [ ] US-02：AI 回复有语音播放（iOS + Android 各验证一次）
- [ ] US-03：问"北京南站附近 1 公里内有什么咖啡馆"返回地图卡片，可全屏查看
- [ ] US-04：界面能看到工具调用卡片
- [ ] US-05：文字逐字显示，语音逐句播放
- [ ] US-06：能切换 LLM 厂商，效果对比明显
- [ ] US-08：游客模式不登录直接可用；杀掉小程序重进，设置与会话历史仍在
- [ ] US-09：系统提示词修改后 AI 行为有变化

### 6.2 质量验收
- [ ] P95 延迟 ≤ 4s（4G/5G 网络下测试 10 次取 P95）
- [ ] ASR 准确率：100 条普通话短句测试，错误率 ≤ 10%
- [ ] 工具调用成功率：50 条地图相关 query 测试 ≥ 95%
- [ ] 录音 60s 不会卡顿 / 崩溃
- [ ] 小程序审核文案 / 截图素材已准备（类目：工具 → 效率）

## 8. 风险与依赖

| 风险 | 等级 | 应对 |
|---|---|---|
| **小程序审核被拒** | 高 | 提前准备：类目选对（工具-效率）、功能描述、截图素材；工具调用类功能需说明用途 |
| **域名备案周期长** | 中 | 第一天启动备案；开发期用开发者工具「不校验合法域名」 |
| 阿里云百炼 API 不稳定 | 中 | 降级到 Deepseek；本地缓存常用回复 |
| 录音权限被拒 | 中 | 引导用户去「右上角…→设置」开启；提供文字输入兜底 |
| 高德 MCP 限速 | 低 | 加缓存 + 失败重试 |
| iOS 录音格式（aac）与 ASR 兼容 | 中 | 后端统一 ffmpeg 转 wav/pcm 后再送 ASR |
| 流式播放卡顿 | 中 | 音频分片缓冲 + InnerAudioContext 边下边播 |
| API 成本失控 | 低 | 日志监控 + 单用户日上限 |
