### 5.2 关键时延拆解

| 阶段 | 耗时目标 | 优化手段 |
|---|---|---|
| 录音采集 | 用户主导 | - |
| ASR 识别 | ≤ 1.0s | 流式识别 / 边说边传 |
| LLM 首次响应 (TTFT) | ≤ 1.5s | 流式 + 并行工具调用 |
| 工具调用 | ≤ 1.0s | MCP 预连接 + 缓存 |
| TTS 首句 | ≤ 1.0s | 分句合成（不必等全文） |
| **总端到端** | **≤ 4.0s** | 多段流水线并行 |

## 8. 关键技术决策

### 8.1 为什么用 WebSocket 而不是纯 REST？
- 录音是**流式输入**（边说边传）
- LLM 是**流式输出**（边想边推）
- TTS 也是**流式输出**（边合边播）
- WebSocket 单连接承载所有事件，避免多次连接握手

### 8.2 为什么用 SSE 备选而不是 gRPC？
- 学习期**降低门槛**：SSE/HTTP 易于调试
- 浏览器原生 EventSource 支持
- 后期可演进到 gRPC（内部服务调用）

### 8.3 为什么用 FastAPI 而不是 Flask / Django？
- 原生 **async / await**，适合 IO 密集型 AI 应用
- 自动 OpenAPI 文档
- Pydantic 数据校验
- 类型注解友好

### 8.4 为什么 LLM 编排在前端而非后端？
- 前端是浏览器，**不适合做重活**
- 后端掌握 API Key、计费、限流更安全
- 后端可以**并发调度** ASR/LLM/TTS，最大化流水线

### 8.5 音频格式选择
- **输入**：浏览器 `MediaRecorder` 默认 webm/opus（兼容性最好）
- **传输**：base64 over WebSocket（或切到 binary frame）
- **处理**：后端用 ffmpeg 转 wav/pcm → ASR
- **输出 TTS**：mp3（体积小 / 浏览器兼容好）

### 8.6 高德 MCP 的接入方式
- 官方提供 **SSE**（Server-Sent Events）端点
- 后端作为 MCP 客户端，通过工具描述符（tools schema）告诉 LLM
- LLM 输出 function call → 后端解析 → 转 MCP 请求

## 9. 模块详细设计

### 9.1 Orchestrator（LLM 编排核心）

```python
# 伪代码
class LLMOrchestrator:
    async def run(self, user_input: str, session: Session, on_event: Callable):
        messages = session.get_messages()
        messages.append({"role": "user", "content": user_input})
        
        # 循环：思考 → 调工具 → 再思考
        for round in range(MAX_TOOL_ROUNDS):
            await on_event({"type": "llm_thinking"})
            
            tool_calls = []
            full_text = ""
            async for chunk in llm_client.stream(messages, tools=MCP_TOOLS):
                if chunk.delta_text:
                    full_text += chunk.delta_text
                    await on_event({"type": "llm_chunk", "text": chunk.delta_text})
                    # 边生成边合成 TTS
                    tts_queue.put(chunk.delta_text)
                if chunk.tool_call:
                    tool_calls.append(chunk.tool_call)
            
            if not tool_calls:
                # 没有工具调用，对话结束
                messages.append({"role": "assistant", "content": full_text})
                break
            
            # 调用工具
            messages.append({"role": "assistant", "content": full_text, "tool_calls": tool_calls})
            for tc in tool_calls:
                await on_event({"type": "tool_calling", "tool": tc.name, "args": tc.args})
                result = await mcp_client.call(tc.name, tc.args)
                await on_event({"type": "tool_result", "tool": tc.name, "summary": str(result)[:200]})
                messages.append({"role": "tool", "tool_call_id": tc.id, "content": json.dumps(result)})
        
        session.save(messages)
```

### 9.2 MCP Client

```python
class MCPClient:
    def __init__(self, endpoint: str):
        self.endpoint = endpoint
        self.tools_cache = None
    
    async def list_tools(self) -> List[Tool]:
        if not self.tools_cache:
            # 调 MCP initialize / tools/list
            self.tools_cache = await self._fetch_tools()
        return self.tools_cache
    
    async def call(self, name: str, args: dict) -> dict:
        # 调 MCP tools/call
        return await self._call_tool(name, args)
```

## 10. 安全设计

| 风险 | 措施 |
|---|---|
| API Key 泄露 | 全部后端持有，前端通过自有后端调用 |
| 提示词注入 | 系统提示词加固 + 工具参数校验 |
| 恶意长输入 | 限制单次输入 ≤ 2000 字 |
| 滥用 / 爬虫 | 速率限制（60 req/min/IP）+ Cloudflare WAF |
| XSS | 前端用 `textContent` 而非 `innerHTML` |
| WebSocket 滥用 | 鉴权 token + 单连接限速 |
| 用户隐私 | 默认不持久化录音；会话历史本地化 |

## 11. 性能与可靠性

### 11.1 性能优化
- **连接复用**：HTTP 长连接 / WebSocket 保持
- **音频流式**：录音边录边传，不等录完
- **LLM 流式**：分片返回
- **TTS 并行**：LLM 边输出边调 TTS 合成
- **缓存**：相同 query 命中本地缓存

### 11.2 可靠性
- **降级链**：
  - 百炼不可用 → 切 Deepseek
  - TTS 失败 → 纯文字
  - ASR 失败 → 提供文字输入
  - 工具失败 → AI 告知用户并继续
- **重试**：所有外部调用支持指数退避重试（最多 3 次）
- **超时**：每个外部调用硬超时 10s
- **健康检查**：`/api/health` 暴露依赖状态

## 12. 监控与日志

### 12.1 日志规范
- **结构化 JSON**：每条日志含 `timestamp / level / request_id / session_id / module / event / duration_ms`
- **链路追踪**：每次对话一个 `request_id`，贯穿 ASR/LLM/MCP/TTS

### 12.2 关键指标
- 请求量 / 成功率 / P50/P95 延迟
- ASR 准确率（人工抽样）
- LLM Token 消耗
- 工具调用次数 / 成功率
- TTS 合成失败率

### 12.3 告警（生产可选）
- 错误率 > 5% 触发
- P95 延迟 > 6s 触发
