## 6. 游客模式（无登录）设计

### 6.1 核心思路
- 小程序启动时用 `wx.getStorageSync('session_id')` 读取；没有则生成 **UUID v4** 存入本地
- 所有请求携带 `X-Session-Id` 头（或 URL 参数），后端以此区分"虚拟用户"
- 会话历史 / 设置 / 录音缓存全部 `wx.setStorageSync` 本地存储
- 后端 SQLite 按 `session_id` 存对话记录（可选，用于换设备恢复 / 日志排查）

### 6.2 好处
- 零注册零门槛，微信内即开即用
- 无需 AppSecret / code2session，个人主体小程序即可
- 后续升级微信登录时，`session_id` 可与 openid 绑定，平滑迁移

## 9. 关键技术决策

### 9.1 为什么录音走 uploadFile 而不是 WS 流式传？
- 微信小程序 `getRecorderManager` 只支持**录完一次性获取文件**（或 frame 回调，但帧级上传复杂且耗电）
- 微信音频单次上限 60s，文件不大（mp3/aac ≈ 0.5-1 MB），`uploadFile` 走微信 CDN 链路快且稳
- 简化协议：ASR 结果通过 REST/WS 返回，无需在 WS 上混传二进制

### 9.2 为什么用 WebSocket 承载对话流？
- LLM 流式输出 + TTS 分片推送，WS 单连接承载所有事件，避免多次握手
- 微信原生 `wx.connectSocket` 支持，且**必须配置 socket 合法域名（wss）**

### 9.3 为什么用 FastAPI 而不是 Flask / Django？
- 原生 async/await，适合 IO 密集型 AI 应用
- 自动 OpenAPI 文档 + Pydantic 校验

### 9.4 为什么 LLM 编排在后端而非小程序端？
- 小程序包可被反编译，**密钥绝不能进小程序**
- 后端掌握 API Key、计费、限流更安全
- 后端可并发调度 ASR/LLM/TTS，最大化流水线

### 9.5 音频格式选择
- **输入**：Android `mp3` / iOS `aac`（微信 RecorderManager 默认格式）
- **处理**：后端 ffmpeg 统一转 `wav/pcm` → 阿里云 ASR（规避 iOS aac 兼容问题）
- **输出 TTS**：`mp3`（体积小 / 微信 InnerAudioContext 播放兼容好）

### 9.6 地图能力分工
- **服务端检索**：高德 MCP（POI 搜索 / 路径规划 / 天气）——LLM 工具调用
- **前端展示**：小程序原生 `<map>` 组件 + 腾讯位置服务 Key（免费额度），渲染标记点、弹窗详情
- 也可选择：小程序 map 组件配置高德数据源（wx 支持指定 map 的 provider）

### 9.7 高德 MCP 的接入方式
- 官方提供 SSE（Server-Sent Events）端点
- 后端作为 MCP 客户端，通过工具描述符（tools schema）告诉 LLM
- LLM 输出 function call → 后端解析 → 转 MCP 请求

## 10. 模块详细设计

### 10.1 Orchestrator（LLM 编排核心）

```python
# 伪代码
class LLMOrchestrator:
    async def run(self, user_input: str, session: Session, on_event: Callable):
        messages = session.get_messages()
        messages.append({"role": "user", "content": user_input})

        # 循环：思考 → 调工具 → 再思考
        for round in range(MAX_TOOL_ROUNDS):
            await on_event({"type": "llm_thinking"})

            tool_calls = []
            full_text = ""
            async for chunk in llm_client.stream(messages, tools=MCP_TOOLS):
                if chunk.delta_text:
                    full_text += chunk.delta_text
                    await on_event({"type": "llm_chunk", "text": chunk.delta_text})
                    tts_queue.put(chunk.delta_text)   # 边生成边合成
                if chunk.tool_call:
                    tool_calls.append(chunk.tool_call)

            if not tool_calls:
                messages.append({"role": "assistant", "content": full_text})
                break

            messages.append({"role": "assistant", "content": full_text, "tool_calls": tool_calls})
            for tc in tool_calls:
                await on_event({"type": "tool_calling", "tool": tc.name, "args": tc.args})
                result = await mcp_client.call(tc.name, tc.args)
                await on_event({"type": "tool_result", "tool": tc.name, "summary": str(result)[:200]})
                messages.append({"role": "tool", "tool_call_id": tc.id, "content": json.dumps(result)})

        session.save(messages)
```

class MCPClient:
    def __init__(self, endpoint: str):
        self.endpoint = endpoint
        self.tools_cache = None

    async def list_tools(self) -> List[Tool]:
        if not self.tools_cache:
            self.tools_cache = await self._fetch_tools()

## 11. 安全设计

| 风险 | 措施 |
|---|---|
| API Key 泄露 | **全部后端持有，小程序端零密钥**（小程序包可反编译，严禁放 Key） |
| 提示词注入 | 系统提示词加固 + 工具参数校验 |
| 恶意长输入 | 限制单次输入 ≤ 2000 字 |
| 滥用 / 爬虫 | 速率限制（60 req/min/IP）+ 游客 session_id 限额 |
| XSS | 小程序 WXML 默认转义，禁止 `rich-text` 注入不可信 HTML |
| WebSocket 滥用 | session_id 校验 + 单连接限速 |
| 用户隐私 | 默认不持久化录音；会话历史本地为主，可清空 |

## 12. 性能与可靠性

### 12.1 性能优化
- **连接复用**：WS 长连接复用；uploadFile 走微信 CDN 链路
- **LLM 流式**：分片返回
- **TTS 并行**：LLM 边输出边调 TTS 合成
- **缓存**：相同 query 命中本地缓存；MCP 工具列表缓存

### 12.2 可靠性
- **降级链**：百炼不可用 → 切 Deepseek；TTS 失败 → 纯文字；ASR 失败 → 文字输入；工具失败 → AI 告知用户并继续
- **重试**：所有外部调用支持指数退避重试（最多 3 次）
- **超时**：每个外部调用硬超时 10s
- **健康检查**：`/api/health` 暴露依赖状态
- **小程序断网**：`wx.onNetworkStatusChange` 顶部提示 + 自动重连 WS
