## 2. API Key 申请清单

| API 名称 | 申请入口 | 计费方式 | 预估成本（学习期） |
|---|---|---|---|
| **阿里云百炼（Qwen / 通义）** | 控制台 → 模型服务 → 申请 API Key | 按 Token 计费 | 新用户有免费额度 |
| **阿里云智能语音 ASR** | 控制台 → 智能语音交互 → 创建项目 | 按调用次数/时长 | 一句话识别 0.0001 元/次 |
| **阿里云智能语音 TTS** | 同上 | 按字符数 | 短文本 0.0002 元/百字 |
| **高德地图 Web JS API** | 控制台 → 应用管理 → Key | 免费（每日配额） | 个人开发者 5000 次/日 |
| **高德地图 MCP** | 官方 MCP 服务（HTTP/SSE） | 免费 | 限速即可 |
| **Deepseek API** | 平台 → API Keys | 按 Token | 注册送额度 |

### Key 存放规范
- **禁止**写入 Git 仓库
- 统一放入项目根目录 `.env` 文件，参考 `.env.example`
- 团队协作时使用 `.env.example` 提交真实 Key 之外的占位符

```bash
# .env.example（提交到 Git）
ALIYUN_BAILIAN_API_KEY=sk-xxxxxxxx
ALIYUN_ASR_APP_KEY=your_app_key
ALIYUN_ASR_TOKEN=your_token
ALIYUN_TTS_APP_KEY=your_app_key
ALIYUN_TTS_TOKEN=your_token
AMAP_JS_API_KEY=your_js_key
AMAP_MCP_ENDPOINT=https://mcp.amap.com/sse
DEEPSEEK_API_KEY=sk-xxxxxxxx
```

## 5. 前端依赖（建议最小集）

为保持 Day-01 的纯前端血统，前端**不引入任何框架**，仅使用：

- 原生 HTML / CSS / JavaScript（ES Module）
- 浏览器原生 `MediaRecorder` API（录音）
- `AudioContext` / `Web Audio API`（播放）
- 阿里云百炼 / 自建后端的 **WebSocket**（流式响应）
- 高德地图 JS API（CDN 引入）

> 进阶可加：**Vite**（构建）+ **TypeScript**（类型），但学习期不强制。

## 6. 部署资源（上线必看）

### 方案 A：极简版（推荐学习期）
- **阿里云 ECS** 1 台（2 vCPU / 4 GB / 40 GB SSD / 5 Mbps 带宽）
- 系统：Ubuntu 22.04 LTS
- 预估月成本：≈ ¥60-100
- 直接 `nohup uvicorn` 或 `systemd` 跑后端
- 前端用 `python -m http.server` 即可

### 方案 B：生产级
- 后端：**Docker** 容器化 + **Nginx** 反代 + **Let's Encrypt** HTTPS
- 前端：阿里云 **OSS** / **CDN** 静态托管
- 监控：阿里云 **ARMS** / 日志服务 **SLS**
- 预估月成本：¥200-500

### 域名（可选）
- 阿里云 / 腾讯云购买 `.cn` / `.com` 域名
- ICP 备案（仅国内服务器需要，≈ 7-20 天）
- 申请免费 **SSL 证书**

## 8. 准备工作的 7 步执行顺序

1. **注册阿里云** + 完成实名（30 分钟）
2. **开通百炼** + 创建 API Key（5 分钟）
3. **开通智能语音** + 创建 ASR/TTS 项目并获取 AppKey/Token（10 分钟）
4. **注册高德** + 创建应用获取 JS API Key + 测试 MCP 连通性（10 分钟）
5. **注册 Deepseek** + 申请 API Key（5 分钟）
6. **本地安装 Python / Node / Git / VSCode / ffmpeg**（20 分钟）
7. **创建 GitHub 仓库** + 配置 SSH Key（5 分钟）

> 总计：约 1.5 小时可以全部跑通。
