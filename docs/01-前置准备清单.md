## 2. 小程序专属前置

### 2.1 注册小程序账号（微信公众平台）

1. 打开 [mp.weixin.qq.com](https://mp.weixin.qq.com) → 立即注册 → 选择「**小程序**」
2. 主体类型：**个人**（本项目游客模式，无需企业认证）
3. 注册完成后进入后台，在「开发 → 开发管理 → 开发设置」中获取：
   - **AppID**：`wx1a2b3c4d5e6f7g8h`（小程序唯一标识，后端配置用）
   - **AppSecret**：仅在后端服务端使用（本项目游客模式**用不到**，不申请亦可）
4. 在「开发 → 开发设置 → 服务器域名」中配置（**上线前**必须，开发期可在开发者工具勾选「不校验合法域名」）：
   - request 合法域名：`https://api.yourdomain.com`
   - socket 合法域名：`wss://api.yourdomain.com`
   - uploadFile 合法域名：`https://api.yourdomain.com`

> 💡 游客模式省掉了「企业主体认证」和「微信登录 code2session」两件事，个人开发者即可跑通全链路。

| API 名称 | 申请入口 | 计费方式 | 预估成本（学习期） |

### Key 存放规范
- **禁止**写入 Git 仓库
- 统一放入项目根目录 `.env` 文件，参考 `.env.example`
- 小程序端**不存放任何密钥**（小程序包可被反编译，密钥只放后端）

```bash
# .env.example（提交到 Git）
ALIYUN_BAILIAN_API_KEY=sk-xxxxxxxx
ALIYUN_ASR_APP_KEY=your_app_key
ALIYUN_ASR_TOKEN=your_token
ALIYUN_TTS_APP_KEY=your_app_key
ALIYUN_TTS_TOKEN=your_token
AMAP_SERVER_API_KEY=your_server_key
AMAP_MCP_ENDPOINT=https://mcp.amap.com/sse
DEEPSEEK_API_KEY=sk-xxxxxxxx
# 可选：小程序地图展示用
TENCENT_LBS_KEY=your_lbs_key
```

## 6. 小程序前端说明（原生，零框架）

- 语言：**WXML + WXSS + JavaScript（原生）**，保持 Day-01 原生血统，不引入 Taro/uni-app
- 录音：`wx.getRecorderManager()`（微信原生录音，**自动处理权限授权弹窗**，无需浏览器权限逻辑）
- 音频播放：`wx.createInnerAudioContext()`（支持边下边播 / 打断）
- 网络：`wx.request`（REST）/ `wx.connectSocket`（WebSocket 流式）/ `wx.uploadFile`（录音文件上传）
- 地图：原生 `<map>` 组件 + 腾讯位置服务 Key（或后端返回坐标，前端渲染标记点）
- 本地存储：`wx.setStorageSync`（游客模式的设置 / 会话历史）
- 无需 npm 构建，微信开发者工具直接运行

## 7. 部署资源（上线必看）

### 方案 A：极简版（推荐学习期）
- **阿里云 ECS** 1 台（2 vCPU / 4 GB / 40 GB SSD / 5 Mbps 带宽），Ubuntu 22.04
- 预估月成本：≈ ¥60-100
- 后端：`systemd` 托管 uvicorn 或 Docker + Nginx 反代
- **必须**：域名 + ICP 备案 + HTTPS（SSL 证书，Nginx 配置 `wss://` 与 `https://`）

### 方案 B：生产级
- 后端：Docker 容器化 + Nginx 反代 + Let's Encrypt HTTPS
- 监控：阿里云 ARMS / 日志服务 SLS
- 预估月成本：¥200-500

### 域名链路（小程序上线硬性要求）
1. 购买域名（`.cn` / `.com`，阿里云 / 腾讯云）
2. **ICP 备案**（仅国内服务器需要，≈ 7-20 天）→ **第一天就启动**
3. 申请免费 SSL 证书（阿里云 / 腾讯云 / Let's Encrypt）
4. Nginx 配置 `https` + `wss` 反代后端
5. 小程序后台配置服务器合法域名（request/socket/uploadFile）

> 💡 开发期完全可以在本地起后端 + 微信开发者工具「不校验合法域名」跑通，**备案与开发并行**，备案好即上线。

## 9. 准备工作的 8 步执行顺序

1. **注册微信公众平台** + 创建小程序，拿到 AppID，**同时发起域名 ICP 备案**（30 分钟 + 备案等待期）
2. **注册阿里云** + 完成实名（30 分钟）
3. **开通百炼** + 创建 API Key（5 分钟）
4. **开通智能语音** + 创建 ASR/TTS 项目并获取 AppKey/Token（10 分钟）
5. **注册高德** + 创建应用获取服务端 Key + 测试 MCP 连通性（10 分钟）
6. **注册 Deepseek** + 申请 API Key（5 分钟）
7. **安装微信开发者工具 / Python / Git / VSCode / ffmpeg**（30 分钟）
8. **创建 GitHub 仓库** + 配置推送（5 分钟）

> 总计：约 2 小时可以全部跑通（不含备案等待期）。
