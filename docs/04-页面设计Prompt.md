# 04 · 语音全栈应用 · 页面设计 Prompt 提示词（微信小程序版）

> **用途**：以下 prompt 可直接喂给 **微信小程序设计工具（如 微信设计 WeUI / 即时设计 / Figma AI）** 或用于指导小程序 UI 开发，产出页面原型或 WXML/WXSS 代码。
> **设计稿基准**：**750rpx 宽**（微信设计规范，1rpx = 0.5px @375 屏宽）
> **风格基调**：现代极简 · 科技感 · 圆角玻璃拟态 · 微动效 · 深色/浅色双主题
> **注意**：小程序 UI 与 Web 不同——使用原生组件（view/text/button/scroll-view/map）、导航栏与 tabBar 由 app.json 控制、胶囊按钮（右上角 ···）不可自定义。

---

## 全局设计 Token（Design Tokens）

```
【设计风格】
- 整体：现代极简 + 玻璃拟态（Glassmorphism），呼吸感与微动效
- 主色调：
  - 背景：#0F1115（深空黑，深色模式）/ #F7F8FA（浅色模式）
  - 主色：#5B8DEF（科技蓝）
  - 强调色：#7C5BEF（紫）/ #00D4A0（青）
  - 文字：#E8EAF0（深色模式）/ #1A1D24（浅色模式）
  - 次文字：#8A8F9C
- 字体：系统字体即可（小程序不引入自定义字体，避免包体积）：
  - 中文：PingFang SC / 系统默认
  - 数字/代码：SF Mono / Menlo
- 圆角：16rpx（小）/ 24rpx（卡片）/ 40rpx（大容器）
- 阴影：0 8rpx 32rpx rgba(91, 141, 239, 0.12)
- 动效：cubic-bezier(0.16, 1, 0.3, 1)；220ms（小）/ 400ms（中）/ 800ms（大）
- 栅格：8rpx 基准
- 安全区：底部 tabBar 之上、iPhone 底部安全区 env(safe-area-inset-bottom)
```

> 小程序全局样式放 `app.wxss`，页面样式放页面级 `*.wxss`；深色模式用 `app.json → darkmode: true` + `theme.json` 配置。

## 页面 1：主聊天页（index）——核心页面

### 完整 Prompt（可直接喂 AI / 指导开发）

```
请设计微信小程序「语音 AI 助手」的主聊天页，整体 750rpx 宽设计稿，深色模式为默认，浅色模式可切换。

【页面结构】（自上而下）
1. 自定义导航栏（navigationStyle: custom，高 88rpx + 状态栏）
   - 左侧：返回按钮（仅子页面）/ 首页显示 Logo「灵语」+ 小字"AI 语音助手"
   - 右侧：设置入口（齿轮图标，跳转设置页）
   - 注意：右上角微信胶囊按钮区域预留，不放置可交互元素

2. 对话流（scroll-view 滚动区域，占满剩余空间）
   - 用户消息：靠右，蓝色渐变圆角气泡（max-width 80%）
   - AI 消息：靠左，玻璃拟态圆角气泡
   - AI 思考中：头像位置三个跳动小圆点 + "正在思考…"
   - AI 流式输出：文字逐字出现（光标闪烁）
   - 工具调用：AI 消息下方嵌入「工具调用卡片」（见页面 3）
   - 地图结果：AI 消息下方嵌入「地图卡片」（见页面 4）
   - 消息底部操作：复制 / 重新生成 / 播放语音按钮

3. 底部输入区（fixed 定位 + 安全区适配）
   - 居中：超大圆形麦克风按钮（直径 128rpx，脉冲呼吸动画）
   - 左右两侧：键盘图标（展开文字输入）/ 历史图标（跳转会话页）
   - 文字输入模式：input + 发送按钮（Enter 发送）

【视觉细节】
- 麦克风按钮未录音：静态麦克风图标 + 缓慢呼吸动画（2.5s 一次）
- 录音中：同心圆扩散 + 音量柱状图（色相蓝→紫）+ 录音时长 mm:ss
- 消息气泡圆角：用户 24rpx（右下角 8rpx）；AI 24rpx（左下角 8rpx）
- 背景：深空黑渐变 + 微弱噪点 + 顶部光晕

【交互行为】
- 长按麦克风（≥200ms）开始录音，松开发送；上滑取消（提示"松手取消发送"）
- 录音超过 60s 自动停止并发送
- 录音权限被拒：弹窗引导「右上角…→设置」开启
- 新消息到达自动滚动到底部；用户上滑查看历史时暂停自动滚动

【动效】
- 麦克风按下 scale(0.95)；消息发送上浮淡入；AI 回复逐字出现
- 录音声波用 canvas 2D 或 CSS 动画，保持 60fps
```

## 页面 2：录音按钮组件（mic-button）

### 完整 Prompt

```
请设计微信小程序语音助手的核心组件——圆形麦克风录音按钮，支持以下状态与动效：

【组件规格】
- 尺寸：128rpx × 128rpx（主界面）/ 悬浮在输入区中央
- 形状：完美圆形；默认玻璃拟态（半透明白 + 背景模糊）
- 主色：#5B8DEF

【状态 1：Idle 待机】
- 静态白色麦克风图标
- 背景 rgba(255,255,255,0.08) + 1rpx 半透明描边
- 呼吸动画：scale 1→1.04→1，2.5s 一次

【状态 2：Pressing 按下】
- scale(0.95) + 阴影内陷；200ms 后进入录音态

【状态 3：Recording 录音中】
- 内圈实心渐变圆（#5B8DEF → #7C5BEF）
- 3 圈扩散同心圆（透明度 0.6→0，1.5s 一波）
- 外圈彩色声波柱（5-7 根随音量变化，蓝→紫）
- 下方显示 mm:ss 计时 + "正在聆听…"

【状态 4：Processing 识别中】
- 旋转加载环 + "识别中…"（约 0.5-1.5s）

【状态 5：Error 错误】
- 变红 #FF5252 1.5s + 轻微抖动 3 次 + "未识别，请重试"

【状态 6：权限被拒】
- 显示"需要麦克风权限"引导按钮 → 跳转设置

【动效要求】
- 全部 cubic-bezier(0.16,1,0.3,1)；录音可视化 60fps
- 小程序实现：CSS animation + wx.createSelectorQuery 监听 touchstart/touchend
- 注意 60s 上限倒计时（剩余 10s 提示）
```

## 页面 3：工具调用卡片（tool-card）

### 完整 Prompt

```
请设计嵌入 AI 消息流的「工具调用卡片」，展示 LLM 调用高德 MCP 工具的过程与结果。

【使用场景】
AI 调用地图/天气工具时，在消息流中显示卡片：工具名、参数、返回摘要、状态。

【卡片结构】（三段式）
┌─────────────────────────────────────┐
│ [图标] 工具名称             [收起/展开] │  ← 标题栏
├─────────────────────────────────────┤
│ 🔵 正在调用 maps_search_around...    │  ← 调用中
│ 参数: { keyword: "咖啡", radius: 1000 }│
├─────────────────────────────────────┤
│ ✅ 已完成 · 0.8s · 返回 5 个结果       │  ← 完成
│ 摘要: 距您最近有星巴克、瑞幸...       │
└─────────────────────────────────────┘

【视觉规范】
- 容器：圆角 24rpx，玻璃拟态，padding 24rpx
- 标题栏：工具图标（地图=放大镜+定位针 / 路径=路线 / 天气=云+太阳）
- 工具名：14px 等宽字体 + 主色；状态灯（调用中=黄色脉冲 / 成功=绿 / 失败=红）
- 参数区：代码风格深底（#1A1D24）+ 等宽 12px，过长折叠"查看更多"
- 结果区：13px 摘要文字 + 可选迷你地图缩略图 + 按钮"在地图中打开"

【动效】
- 卡片出现：左滑入 + 淡入 300ms
- 调用中：状态灯脉冲；完成：变绿 + 轻 bounce；失败：抖动 2 次
- 展开/收起：高度动画 200ms
```

## 页面 4：地图结果卡片（map-card）+ 全屏地图

### 完整 Prompt

```
请设计 AI 回复中的「地图结果卡片」，用于展示附近搜索 / 路径规划结果，并可全屏查看。

【卡片规格】
- 宽度：撑满消息气泡，最大 560rpx

- 小程序原生 <map> 组件（width/height 100%，lazy-load）

【全屏态】（独立页面 pages/map-detail）
- 全屏 map + 底部结果列表（半屏，可上滑展开）
- 每条结果：图标 + 名称 + 地址 + 距离 + 评分
```

## 小程序 UI 开发要点（WXML/WXSS 注意项）

1. **rpx 单位**：设计稿 750rpx 宽，所有尺寸用 rpx 自适应
2. **导航栏**：首页用 `navigationStyle: custom` 自定义沉浸式；子页面可保留默认导航
3. **胶囊按钮**：右上角微信胶囊不可控，custom 导航时预留空间（约 90px 宽）
4. **tabBar**：如有"聊天 / 历史"双 tab，在 `app.json` 配置 tabBar（icon 用本地 png，≤40KB）
5. **安全区**：底部输入区 `padding-bottom: env(safe-area-inset-bottom)`
6. **原生组件**：input / slider / switch / picker / map 用微信原生，保证一致性
7. **深色模式**：`app.json` 开启 `"darkmode": true` + `theme.json` 定义主题变量
8. **音频播放**：InnerAudioContext 需 `obeyMuteSwitch: false` 避免静音键拦截
