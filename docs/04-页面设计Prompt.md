# 04 · 语音全栈应用 · 页面设计 Prompt 提示词

> **用途**：以下 prompt 可直接喂给 **Figma AI** / **v0.dev** / **GPT-4o 图像** / **Claude Artifacts** / **Cursor Composer** 等设计 / 前端生成工具，**一键产出页面原型或代码**。  
> **风格基调**：现代极简 · 科技感 · 圆角玻璃拟态 · 微动效

---

## 全局设计 Token（Design Tokens）

```
【设计风格】
- 整体风格：现代极简 + 玻璃拟态（Glassmorphism），强调呼吸感与微动效
- 主色调：
  - 背景：#0F1115（深空黑） / #FFFFFF（明亮模式）
  - 主色：#5B8DEF（科技蓝）
  - 强调色：#7C5BEF（紫）/ #00D4A0（青）
  - 文字：#E8EAF0（深色模式） / #1A1D24（明亮模式）
  - 次文字：#8A8F9C
- 字体：
  - 中文：PingFang SC / 思源黑体
  - 英文：Inter / SF Pro
  - 代码：JetBrains Mono
- 圆角：12px（小元素） / 16px（卡片） / 24px（大容器）
- 阴影：0 8px 32px rgba(91, 141, 239, 0.12)
- 动效曲线：cubic-bezier(0.16, 1, 0.3, 1) ease-out
- 动效时长：220ms（小） / 400ms（中） / 800ms（大）
- 栅格：8px 基准
- 断点：375 / 768 / 1024 / 1440
```

## 页面 1：主聊天界面（Home / Chat）

### 完整 Prompt（可直接喂 AI）

```
请为我设计一个 Web 端 AI 语音助手的主聊天界面，要求如下：

【页面定位】
这是语音全栈 AI 助手的主界面，用户通过对话与 AI 交互，AI 可以听（语音输入）、想（LLM 推理）、做（调用工具）、说（语音输出）。

【整体布局】
1. 顶部导航栏（高 64px）
   - 左侧：Logo + 产品名"灵语"
   - 中部：当前会话标题（可点击切换会话）
   - 右侧：设置按钮（齿轮图标）+ 主题切换按钮（月亮/太阳）
2. 左侧会话列表（宽 280px，可折叠）
   - "新建会话"按钮（顶部）
   - 会话历史（按时间倒序，每条显示标题 + 时间）
   - 悬停显示删除按钮
3. 中央对话区（自适应宽度）
   - 顶部小条：当前 LLM 模型标识（如"通义 Qwen-Plus"） + 工具调用开关
   - 对话流：用户消息靠右、AI 消息靠左
     - 用户消息：圆角气泡 + 蓝色背景
     - AI 消息：圆角气泡 + 玻璃拟态背景
     - 工具调用以独立卡片形式嵌入 AI 消息下方
   - 底部输入区（粘性）
     - 中央：超大圆形麦克风按钮（直径 80px，带脉冲呼吸动画）
     - 左右两侧：文字输入框（可隐藏）和键盘图标切换
4. 右侧工具面板（宽 360px，可折叠）
   - 实时显示 AI 思考过程
   - 工具调用记录（工具名 + 参数 + 返回摘要）
   - 性能监控小卡片（TTFT、ASR 时长、TTS 时长）

【视觉细节】
- 麦克风按钮：未录音时显示静态麦克风图标；录音中显示声波动画（同心圆向外扩散 + 渐变）
- AI 正在思考时，AI 头像位置显示三个跳动的小圆点
- AI 流式输出时，文字逐字出现（带轻微光标闪烁）
- 工具调用卡片：左侧有工具图标 + 名称，右侧有"展开/收起"按钮
- 整体背景：深空黑渐变 + 微弱噪点纹理 + 顶部光晕效果

【交互行为】
- 长按麦克风开始说话（≥ 200ms 才识别为有效录音）
- 录音中显示实时声波可视化（彩虹色柱状图）
- 松开麦克风自动结束录音并发送
- 文字输入框支持 Enter 发送、Shift+Enter 换行
- AI 消息可点击"复制"、"重新生成"、"播放"按钮
- 滚动到底部有"自动跟随最新消息"行为，新消息来时若已在底部则自动滚动

【响应式】
- 桌面（≥ 1024px）：三栏布局（左中右）
- 平板（768-1023px）：两栏布局（隐藏右侧工具面板，可点击展开）
- 移动（< 768px）：单栏布局（侧边栏抽屉式）

【微动效】
- 麦克风按下：scale(0.95) + 阴影变深
- 消息发送：从底部上浮 + 透明度 0→1
- AI 回复：逐字出现，伴随轻微"沙沙"打字声（可关闭）
- 工具卡片出现：从左侧滑入 + 透明度
- 主题切换：全局颜色淡入淡出 400ms

【无障碍】
- 所有按钮带 aria-label
- 焦点状态明显（2px 主色描边）
- 支持键盘操作（Tab 导航、Enter 提交）
- 录音失败有屏幕提示 + 文字重试入口
```

## 页面 2：录音交互组件（Voice Button）

### 完整 Prompt

```
请设计一个语音输入的核心组件——圆形麦克风按钮，包含以下状态和动效：

【组件规格】
- 尺寸：80px × 80px（默认） / 桌面端 / 移动端 64px × 64px
- 形状：完美圆形
- 默认状态：玻璃拟态背景（半透明白 + backdrop-blur 20px）+ 麦克风图标
- Hover 状态：微微上浮（translateY(-2px)）+ 阴影加深
- 主色：#5B8DEF

【状态 1：Idle 待机】
- 静态麦克风图标（白色）
- 背景：rgba(255,255,255,0.08) + backdrop-blur
- 边框：1px solid rgba(255,255,255,0.12)
- 缓慢的脉冲呼吸动画（2.5s 一次）：scale 1→1.04→1，shadow 透明度 0.3→0.5→0.3

【状态 2：Pressing 按下】
- 立即响应：scale(0.95) + 阴影内陷
- 背景色变深 10%
- 准备 200ms 后进入 Recording 状态

【状态 3：Recording 录音中】
- 整个按钮变成声波可视化
  - 内圈：实心圆 + 渐变（#5B8DEF → #7C5BEF）
  - 中圈：3 圈扩散的同心圆（透明度从 0.6→0，每 1.5s 一波）
  - 外圈：彩色声波柱（5-7 条柱状图随音量实时变化高度，色相从蓝到紫）
- 中央显示一个实心麦克风图标（白色）
- 录音时长显示在按钮下方（mm:ss 格式）
- 文字提示："正在聆听…"

【状态 4：Processing 处理中】
- 按钮内显示加载动画（旋转的环）
- 文字提示："识别中…"
- 此状态通常持续 500-1500ms

【状态 5：Error 错误】
- 按钮变红色（#FF5252）1.5s
- 文字提示："未识别，请重试"
- 轻微抖动动画（translateX 4px 3 次）

【辅助元素】
- 下方有文字提示，3s 后自动消失
- 麦克风权限被拒绝时，显示"请授权麦克风权限" + 跳转设置链接

【动效要求】
- 状态切换全部使用 cubic-bezier(0.16, 1, 0.3, 1) ease-out
- 录音可视化用 requestAnimationFrame，60fps 流畅
- 所有动画可以 prefers-reduced-motion 时自动降级
```

## 页面 3：工具调用展示卡片（Tool Call Card）

### 完整 Prompt

```
请设计一个嵌入在 AI 回复中的工具调用卡片，用于可视化展示 LLM 调用工具的过程。

【使用场景】
当 AI 调用高德地图 MCP 工具（POI 搜索、路径规划、天气查询等）时，在 AI 消息流中显示一个独立的卡片，包含工具名称、参数、返回结果摘要。

【卡片结构】
- 容器：圆角 16px，玻璃拟态背景
- 内边距：16px
- 宽度：撑满父消息气泡，最大 100%
- 阴影：0 4px 16px rgba(0,0,0,0.08)

【三段式布局】
┌─────────────────────────────────────┐
│ [图标] 工具名称              [收起/展开] │  ← 标题栏
├─────────────────────────────────────┤
│ 🟦 正在调用 maps_search_around...    │  ← 调用中
│ 参数: { keyword: "咖啡", radius: 1000 }│
├─────────────────────────────────────┤
│ ✅ 已完成 · 耗时 0.8s · 返回 5 个结果   │  ← 完成
│ 摘要: 距离您最近的有星巴克、瑞幸...   │
└─────────────────────────────────────┘

【视觉规范】
- 标题栏：
  - 工具图标（左侧）：不同工具有不同图标
    - 地图搜索：放大镜 + 定位针
    - 路径规划：路线图
    - 天气：云朵 + 太阳
  - 工具名称：等宽字体（JetBrains Mono），14px，主色
  - 状态指示灯：调用中（黄色脉冲）/ 成功（绿色）/ 失败（红色）
  - 右侧收起/展开箭头（▲/▼）

- 参数区域：
  - 代码风格背景（#1A1D24 浅色边框）
  - 等宽字体，12px
  - 过长自动折叠，显示"查看更多"

- 结果区域：
  - 文字摘要：常规字体，13px
  - 可选：嵌入一个迷你地图预览（128px × 96px）
  - 操作按钮："查看完整结果" / "在地图中打开"

【地图结果特殊样式】
- 搜索 POI 后，渲染一个 240px 高的简易地图缩略图
- 标记点用蓝色水滴
- 缩放控件简化

【动效】
- 卡片出现：从左侧滑入 + 透明度 0→1，300ms
- 调用中：状态指示灯脉冲（1s 一次）
- 完成：状态灯变绿 + 轻微 bounce
- 失败：状态灯变红 + 卡片水平抖动 2 次
- 展开/收起：高度动画 200ms

【可访问性】
- 卡片整体可被屏幕阅读器识别为"工具调用卡片：{工具名}"
- 展开/收起按钮带 aria-expanded
- 状态变化通过 aria-live="polite" 通知
```
